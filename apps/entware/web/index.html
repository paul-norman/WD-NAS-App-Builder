Entware

Entware adds the opkg package manager to the NAS, with thousands of extra command line tools. It is used over SSH:

opkg update               # refresh the package list
opkg find '*name*'        # search for a package
opkg install <package>    # install a package
opkg list-installed       # show installed packages
opkg upgrade              # update installed packages

Packages are kept in Nas_Prog/_entware/opt (mounted on /opt) and root's home folder in Nas_Prog/_entware/home, both of which survive reinstalls. The NAS shows an alert when package updates are available.

See the Entware wiki for more.
